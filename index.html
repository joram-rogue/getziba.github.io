Privacy Policy

Last updated: July 3, 2026

1. Who we are

Zibahub (“Ziba”, “we”, “us”) is a social commerce and delivery marketplace connecting traders and buyers in Uganda. Contact: getziba6@gmail.com

2. What we collect

  • Account info: name, username, email, phone number, mobile money number
  • Profile content: photos, posts, product listings, messages
  • Rider info: national ID number, photo, operating zone, payout details
  • Device info: device type, push notification token
  • Usage data: posts liked, orders placed, searches made

3. Why we collect it

  • To operate the marketplace and process orders
  • To verify rider identities before approval
  • To send push notifications for orders, deliveries, and messages
  • To process payments via Pesapal
  • To improve the app experience

4. Who we share it with

  • Pesapal — to process payments
  • Supabase — secure database and file storage
  • Firebase — push notifications only

We never sell your data to advertisers. Ever.

5. Your rights

You can request deletion of your account and all data at any time by emailing getziba6@gmail.com. We process deletion requests within 7 days.

6. Data security

All data is stored on Supabase with row-level security enabled. Passwords are never stored — authentication is handled by Supabase Auth.

7. Children

Ziba is not intended for users under 13.

8. Changes

We’ll notify users of material changes via in-app notification.
